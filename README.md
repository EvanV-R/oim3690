
# OIM3690 — Web Technologies and AI

This repository contains my coursework, JavaScript exercises, and web development projects for OIM3690 at Babson College.

## Mini Project 2 — Daily Productivity Tracker

I created an interactive JavaScript website that helps users track daily habits, organize tasks, calculate productivity scores, and view their progress over time.

The website includes task management, local storage, and a weekly productivity chart.

- [Live Website](https://evanv-r.github.io/daily-productivity-tracker/)
- [GitHub Repository](https://github.com/EvanV-R/daily-productivity-tracker)

## Mini Project 3 — Airport Connection Weather Risk Calculator

I built a website that helps travelers estimate the weather-related risk of missing a connecting flight.

The calculator uses the Open-Meteo weather API to retrieve weather forecasts and combines the information with connection time to estimate risk.

I chose this idea because I frequently travel and wanted to create a tool that helps passengers better prepare for airport connections.

- [Live Website](https://evanv-r.github.io/airport-connection-risk/)
- [GitHub Repository](https://github.com/EvanV-R/airport-connection-risk)
- [Open-Meteo API Documentation](https://open-meteo.com/en/docs)

I created a JavaScript webpage that fetches information from a public API and displays the result on the page.

### Ask AI — November 3

I created a simple AI chatbot using JavaScript, a Vercel serverless function, and the OpenRouter API.

Users can type a question, submit it, and receive an AI-generated response.

The OpenRouter API key is stored securely in Vercel environment variables rather than in the public GitHub repository.

- [Ask AI — Live Vercel Website](https://oim3690-bice.vercel.app/ai-chat.html)
