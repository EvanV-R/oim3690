## Mini Project 3 — Airport Connection Weather Risk Calculator

I built a website that helps travelers estimate the weather-related risk of missing a connecting flight.

The tool uses the Open-Meteo weather API to retrieve forecast information and combines weather conditions with connection time to estimate risk.

- [View my live website](https://evanv-r.github.io/airport-connection-risk/)
- [View my GitHub repository](https://github.com/EvanV-R/airport-connection-risk)
- [Open-Meteo API documentation](https://open-meteo.com/en/docs)
