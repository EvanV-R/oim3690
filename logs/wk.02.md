### 1. What I worked on
This week I worked on creating my own HTML webpage using VS Code. I practiced using different HTML tags, adding headings, paragraphs, and images, and opening my webpage through Live Server.

### 2. What gave me trouble / Where I'm still stuck
I still get confused about when to use certain HTML tags and why some need closing tags while others don't. I also had trouble understanding how file paths work and why an image won't show up if the filename isn't correct.

### 3. Something new I learned
I learned that websites don't just appear when you type in a URL. The browser uses DNS to find the server, sends a request, and receives files that it turns into the webpage we see. I didn't realize how many steps happen behind the scenes.

### 4. Something I noticed about working with AI
I noticed that AI can make coding much easier by explaining what different parts of the code mean. However, when AI gives me the entire code, I don't always understand how it works. Typing the HTML myself helped me understand it better.
